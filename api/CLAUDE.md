## Flutter App (`lifeondeck/`)

### Commands

```bash

flutter pub get

```

Setup checklists for Firebase, Android signing, iOS provisioning live in [lifeondeck/PLATFORM_TODO.md](lifeondeck/PLATFORM_TODO.md). `lib/firebase_options.dart` is generated by `flutterfire configure`.

### Architecture

```
lib/
  main.dart                  # entry point: Firebase init, orientation lock, runApp
  app.dart                   # YugiLifeCounterApp — MaterialApp + AppTextScope wrapper
  core/
    constants.dart           # SupportedTcg enum, storage keys, palette, utility fns
    config.dart              # AppRuntimeConfig (language ValueNotifier), AppOrientationLock
    ux_state.dart            # AppUxStateStore (SharedPreferences: onboarding, seen tips)
  l10n/
    app_strings.dart         # AppStrings + AppTextScope — inline EN/IT catalog
  models/                    # pure data / domain models (serializable)
  services/
    api_client.dart          # Dio wrapper; reads JWT from FlutterSecureStorage per request
    auth_service.dart        # ChangeNotifier; Firebase → server JWT; persists user
    sync_service.dart        # ChangeNotifier; push/pull cycle with auto-sync timer
  screens/                   # one folder per feature: onboarding, game_selection,
                             #   home, duel, mtg, history, sideboard, customize, profile
  widgets/                   # shared widgets (SyncStatusBadge, ClearableTextField,
                             #   DeckFormDialog, MatchEditorDialog, SearchableComboField,
                             #   TextPromptDialog)
```

**State management:** plain `setState` inside `StatefulWidget` + `ChangeNotifier` for services (`AuthService`, `SyncService`). No Provider, Bloc, or Riverpod package — services are instantiated directly in `_HomeScreenState` and passed down as constructor arguments.

**Navigation:** imperative `Navigator.push/pop` with typed results. Each screen returns data to its caller via `Navigator.pop(result)`.

**Persistence:**
- App state (game records, sideboard decks, settings) → `SharedPreferences` as JSON strings; all keys are in `_HomeScreenState` static consts.
- JWT token and logged-in user → `FlutterSecureStorage` (keys: `jwt_token`, `current_user`).

**Sync flow:** `SyncService` runs a push/pull cycle (`syncNow()`). Push serialises local state via `onGetPayload` callback; pull delivers a `Map` to `onApplyPull` callback — both callbacks are wired in `_HomeScreenState`. `markDirty()` must be called after every local mutation so the next auto-sync (default 5 min) knows to push.

**Auth flow:** `AuthService.signInWithGoogle()` → Firebase popup/provider → Firebase ID token → POST `/auth/firebase` → server JWT stored in `FlutterSecureStorage`.

**i18n:** custom `AppStrings` catalog (EN + IT). `AppTextScope.of(context).t('key')` anywhere in the tree. `flutter_localizations` is imported only for `MaterialApp.localizationsDelegates`. Add strings to the `_catalog` map in `lib/l10n/app_strings.dart`.

**TCGs supported:** `yugioh`, `mtg`, `riftbound`, `lorcana`. `riftbound` and `lorcana` are stubbed (no duel screen). The `SupportedTcg` enum and `supportedTcgStorageKeys` set live in `core/constants.dart`.

**Android/iOS login:** Firebase Google sign-in for Android/iOS is TODO (see commit `c93730a`); currently only web popup flow is wired.

## API (`lifeondeck-api/`)

### Commands

```bash
# Run from lifeondeck-api/
dotnet build
dotnet run --project LifeOnDeck.Api
dotnet watch --project LifeOnDeck.Api      # hot reload

# EF Core migrations (run from LifeOnDeck.Api/)
dotnet ef migrations add <Name>
dotnet ef database update
```

Solution file: `LifeOnDeck.slnx` (`.slnx` format, requires VS 2022+).

### Architecture

ASP.NET Core 10, EF Core + Npgsql (PostgreSQL), JWT bearer auth, .NET 10.

**Endpoints:**

| Method | Route | Auth | Description |
|--------|-------|------|-------------|
| POST | `/api/v1/auth/firebase` | No | Exchange Firebase ID token → app JWT |
| GET  | `/api/v1/sync?since=<ISO8601>` | JWT | Pull changes since timestamp |
| POST | `/api/v1/sync` | JWT | Push batch of changes |

**Sync protocol:** last-write-wins by client `UpdatedAt`. Soft deletes use `DeletedAt`; EF global query filters exclude soft-deleted rows by default — use `.IgnoreQueryFilters()` when the Pull/Upsert paths need them.

**Data model:** `GameRecordEntity`, `SideboardDeckEntity`, `AppSettingsEntity` store their payload as a raw JSON blob in a `Data string` column. The server is schema-agnostic for those blobs.

**Required configuration before running:**

| Key | Where | Notes |
|-----|-------|-------|
| `ConnectionStrings:Default` | `appsettings.Development.json` | PostgreSQL connection string |
| `Jwt:SecretKey` | env var or user secrets | Replace placeholder; min 32 chars |
| `Firebase:ProjectId` | `appsettings.json` | Firebase project ID |

CORS is fully open (`AllowAnyOrigin`) — restrict before deploying to production.
